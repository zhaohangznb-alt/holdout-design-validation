# Independent non-kinase target panel — frozen before its model scores

Date: 2026-10-03. This is an algorithm-evaluation extension on different targets from the same database, not an independently curated database or a prospective laboratory validation.

Candidate list fixed before retrieval and prediction: human ACHE/CHEMBL220/P22303, DPP4/CHEMBL284/P27487, PTGS2/CHEMBL230/P35354, CA2/CHEMBL205/P00918, HDAC1/CHEMBL325/Q13547, PDE4D/CHEMBL288/Q08499. These are a purposive set of six non-kinase enzymes spanning different protein families, not a random or exhaustive target screen. Each identity must be confirmed from the official target response as human SINGLE PROTEIN with the expected accession. Do not substitute targets based on results. Retain every eligible candidate and report failures.

Source: official ChEMBL API, release 37; save original JSON responses, request URLs, retrieval times and hashes. Abort if release changes during retrieval. No access-control circumvention or retry after HTTP 403/429. Paged read requests may resume from hash-verified cached responses. The offline reproduction entry consumes these frozen responses, not a future mutable API.

Database-level cleaning: matching human target, standard_type IC50, standard_relation =, standard_flag 1, potential_duplicate 0 or null, no data_validity_comment, standard_units nM, positive finite standard_value, finite pchembl_value, integer document_year and complete activity/assay/document/structure identifiers. Preserve database pChEMBL precision. RDKit canonical SMILES preserves stereochemistry, without salt-parent or tautomer normalization. Murcko scaffolds use the canonical acyclic molecule as a fallback when the framework is empty. Aggregate median pChEMBL by canonical structure × assay × document × year × scaffold, retaining activity IDs and original records. Database annotations are the evidence source; there is no claim that every publisher original was audited.

Candidate eligibility: at least 1500 cleaned activity records, 1000 distinct canonical molecules, 20 documents, document-year span >=10 years, and >=100 test contexts in both exact-identity routes. Screening uses data counts only and never scores. Show every candidate's flow/counts, including excluded candidates. Freeze selected targets and partition hashes before fitting.

Source-document split: sort document IDs and permute with numpy default_rng(42); use round(0.70*n) train, round(0.15*n) valid, remaining test, bounded to keep all three nonempty. Chronological split: accumulate latest whole years until >=20% of aggregated rows; accumulate preceding whole years until >=15% of the same original total for validation; all earlier years train. No cutoffs selected by scores. Apply exact separation in train→valid→test order. Additional scaffold filtering removes prior kept train scaffolds from valid and prior kept train+valid scaffolds from test, while retaining the exact-route training set. Freeze both broad and operational views. Operational eligibility requires assay_type B, bao_format BAO_0000357, relationship_type D and the matching target, applied after the same broad partitioning/filtering. No source-specific overrides. Small operational/scaffold test populations remain reported, not substituted; fewer than100 test contexts are explicitly marked below the primary screening threshold.

Models/metrics identical to PROTOCOL.md: RF 500 trees/min leaf2/sqrt, seeds42/53/67, Ridge alpha1/lsqr, first-tie Tanimoto1-NN, binary Morgan radius2/2048/nonchiral, matching training mean, MSE/MAE/RMSE/D/skill. No tuning. Equal target weight, RF seed medians. Route contrasts are descriptive comparisons of different populations. No claim of transfer-learning performance: each target has its own freshly fitted models.

Primary readout: report year-exact minus source-exact and source-scaffold minus source-exact for each model/target, plus all four route skills and absolute errors. Compare patterns with the original kinase panel without pooling them as independent replicates. All outcomes, including zero/negative skills and opposite route contrasts, are retained.
